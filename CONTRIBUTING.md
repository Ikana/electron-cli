# Contributing

This project is a learning-first Rust CLI for Electron workflows.

## Local Checks

```sh
npm run format
npm run lint
npm test
```

## Project Direction

Start with small, inspectable behavior:

- diagnostics before orchestration
- structured output before terminal polish
- wrappers before rewrites
- documented tradeoffs before compatibility claims

Avoid presenting the project as official Electron tooling. It is independent, experimental, and community maintained.
